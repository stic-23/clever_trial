# clever_trial
Repository containing data analyst trial assessment for Clever.

I have uploaded code and files in this repository, with descriptions outlined below. 

### Data
I have uploaded five csvs of data that I downloaded from the trial data shared with me. The csvs contain data on sales, calls, agents, customers and markets. Additionally, I have included the original project README.

**agents.csv** provides information on real estate agents in our network

**calls.csv** indicates the times at which each customer called the company and the outcome of that call

**customers.csv** lists basic information about each customer - a unique ID, name, address, etc.

**markets.csv** provides information on the fifty markets served by our company

**sales.csv** indicates the time of a successful sale, identifying the CustomerID, the time of the sale, and the value of the property sold

**Data Dictionary.csv** is the original README with detailed descriptions of variables. 

### Analysis Write Up
**Analysis Qs.docx** is the written deliverable for the take home assessment. This document includes market insights, agent insights (and ranking table) and the process write up. 

### Analysis Script
I used R via RStudio to analyze the data. I have included the RMarkdown script as **cleverassessment.Rmd**. The script includes a base set of common packages that I like to automatically include in all my scripts. There are also notations from me documenting my process and explaining the purpose of the code chunks.
